## Source section 41: PWA

The application should be designed so PWA support can be added later.

Do not require a native mobile application for MVP.

The primary target is:

```text
Responsive Web App
+
PWA-ready architecture
```

Implement PWA support only as a separate post-MVP task after acceptance.
